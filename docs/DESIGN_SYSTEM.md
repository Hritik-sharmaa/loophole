# Loophole — Design System

**Soft Shelf** (ADR-047, replacing Sticker Lab, ADR-020). A lavender canvas with white cards that have a thin outline and a soft violet-tinted shadow; Sunflower pill buttons; Violet for where you are; glossy 3D-looking tiles and stickers; sparkles. Built from the developer's references: Readly (yellow buttons, soft cards), Ruang Edit (purple, sparkles, 3D tiles, pill highlight inside a headline), a kids' reading app (the course path as an illustrated map) and Humation (doodle avatars). The characters are the crew (ADR-028), now built from the avatar maker's parts (ADR-046) so guides and learners look alike. The logo is the loop.

## 1. Principles

1. **One colour, one meaning.** Sunflower = your move now (the main button, the lesson to start). Violet = where you are and what you've done (active nav, selected, done lessons, the walked path, passed tests, the featured card). Pink = your rival and a failed check. Lemon = rewards and labels. Ink = text and code. Tile pastels (pink, lilac, sky, orange, mint) and map seasons are scenery: never text, buttons or state. Language logos keep their own colours (ADR-027).
2. **Motion shows the product working** (ADR-048). The landing page is a set of GSAP scenes that play the real flow (a bug fixed and graded, a lesson step by step, the map walked, a duel won). In the app, motion answers an action (unlocks, XP gains, duel wins) plus three ambient touches: pages fade in, the active nav and tab pill slides, and a unit's road draws itself with its books hopping up the first time it is seen. Loops run only while on screen. Reduced motion always gets the finished state, still.
3. **Soft, not loud.** Cards are white with a 1 px `border-muted` outline and a soft shadow (`sticker`), never a thick outline or a hard offset shadow. Buttons are pills; they shrink slightly on press. One loud thing per screen: the Sunflower button, or one Violet featured card.
4. **Illustrated, not generic.** Every screen gets one drawn detail from the product's world: the crew, a doodle avatar, a glossy sticker, a course tile, the map. No stock icons as decoration.

## 4. Spacing, radius, elevation

- Spacing: Tailwind's default 4 px scale.
- Radius: cards `24px` (`rounded-card`), buttons, chips and badges are pills (`rounded-full`, `rounded-badge`), 3D tiles `28%` of their size, the landing sheet and unit maps `32–40px`.
- Outlines: 1 px `border-muted` on cards, chips and inputs. Selected things get a Violet outline or fill instead.
- Soft shadows, tinted violet: `press` (buttons), `sticker` (the main card of a region), `sticker-sm` (small floating things), `sun` (the Sunflower button's golden glow).
- Glass: the header and phone tab bar are 85–95 % white with a backdrop blur.

## 5. Motion

| Token    | Value                                             | Use                                       |
| -------- | ------------------------------------------------- | ----------------------------------------- |
| press    | 150 ms, scale 0.97                                | Button press and release                  |
| base     | 300–500 ms                                        | Node unlock, XP count-up                  |
| pulse    | 1.6 s loop                                        | The "start here" book's glow              |
| bob      | 3.2 s loop, 7 px                                  | Floating stickers (duel stage, landing)   |
| ease-pop | `cubic-bezier(0.34, 1.56, 0.64, 1)`               | Overshoot on unlock and landing entrances |
| spring   | `{ type: 'spring', stiffness: 400, damping: 15 }` | Framer Motion equivalent                  |

Framer Motion runs the app's motion; `<MotionConfig reducedMotion="user">` in `app/providers.tsx` turns it all into instant changes for reduced motion. GSAP runs the landing page only (`components/landing/gsap.ts`); each scene uses `gsap.matchMedia()` with `MOTION_OK` and sets a still, finished state otherwise. Elements a scene reveals carry `data-gsap-hide` so they never flash before animating. CSS loops (pulse, bob) stop through the reduced-motion rule in `globals.css`. Confetti uses Sunflower, Lemon, Violet and Pink.

## 7. Tailwind config (v4, ADR-013)

Tailwind v4 has no `tailwind.config.ts`; tokens are CSS variables in `@theme` blocks in `apps/web/app/globals.css`. Each variable becomes utilities by its prefix: `--color-violet` → `bg-violet`, `text-violet`, `fill-violet`, `stroke-violet`; `--radius-card` → `rounded-card`; `--shadow-sticker` → `shadow-sticker`; `--animate-bob` → `animate-bob`. Defining `--color-orange` adds `bg-orange` alongside Tailwind's built-in `orange-50`…`950` scale; use only the tokens in §2.

`globals.css` is the source of truth for exact values. Fonts map through `@theme inline`: `--font-display` → `--font-lexend`, `--font-sans` → `--font-jakarta`, `--font-mono` → `--font-jetbrains`. The body is plain Canvas.

## 8. Do and don't

- Do use Sunflower for one thing per screen region. Don't put three yellow buttons side by side.
- Do give a region one sticker card; nested blocks use a plain bordered block or a Surface panel. At most one Violet featured card per screen.
- Do use a glossy sticker or a 3D Tile where an icon carries a reward or a moment (XP, streak, wins, bugs). Keep plain line icons for controls.
- Do draw the map, the crew and avatars by hand in SVG. Don't use a diagram library, stock illustrations or an icon pack for them.
- Don't go back to thick Ink outlines or hard offset shadows on cards and buttons; the doodle outline belongs to the characters only.
- Don't copy Duolingo's, Readly's, Ruang Edit's or Humation's assets, characters or mascots: the references set the mood, everything is drawn for Loophole.
